# AI Computer Agent — Project Report

## Objective
Build a permission-first AI system that can understand a user's task, inspect a computer screen, operate approved computer controls, use development tools, and later communicate with Arduino/ESP32/PLC gateways.

## Core layers
1. AI brain and planner
2. Vision/screen understanding
3. Permission and approval layer
4. Computer-control tools
5. Browser/developer tools
6. Hardware gateway
7. Dashboard, memory and audit logs

## Important boundary
The AI should assist with legitimate automation and development work. It must not silently perform destructive, financial, credential, production, or safety-critical actions.

## Budget strategy
Start with the user's existing PC and open-source/local components where practical. External model/API usage may introduce separate costs.
