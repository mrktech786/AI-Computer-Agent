# AI Computer Agent

Phase-1 foundation for a safe AI computer-control agent.

## Includes
- Python agent core
- Screen capture
- Mouse/keyboard control
- Permission-first security layer
- Allowlisted terminal runner
- Hardware gateway documentation

## Start

```bash
python -m venv .venv
# Windows
.venv\\Scripts\\activate
pip install -r requirements.txt
python -m agent
```

Terminal execution is disabled by default. High-impact actions must require explicit approval.
